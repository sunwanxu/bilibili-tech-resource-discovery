## 新版 STM32 从入门到精通：有实质内容，适合标准库基础训练

P4 使用芯片框图介绍 Cortex-M3、Flash、SRAM、DMA、总线和外设关系。P30 不只是展示 PWM：它从数据手册定位定时器引脚，逐步配置时钟、GPIO、定时器结构体，并用预分频和周期推导约 1 kHz 输出。P58 覆盖 ADC 引脚、时钟上限与分频、连续转换、中断、NVIC、12 位采样值到电压的换算，并以 3.3 V 输入做结果检查。

因此，旧版仅根据 P1 给出的 3 分推荐明显偏低。课程确实包含原理、API、代码和实验闭环；不足是表达重复较多，抽样内容以标准外设库和基础外设为主，尚未看到大型综合项目、复杂调试或跨模块架构。

## 铁头山羊：教学设计在技术章节中得到验证

P28 从 W25Q64 的用途和 SPI 接线开始，区分 MISO/MOSI/SCK/NSS，依据引脚表选择复用位置，再依据芯片手册选择输入输出模式和满足频率要求的最小 IO 速度，最后逐行完成初始化。证据链是“器件与总线 → 手册 → 电路 → 参数 → 代码”，而不是只念 API。

P48 先产生待测 PWM，再配置串口、定时器时基、输出比较、输入捕获和从模式控制器；讲解涉及结构体初值、ARR/CCR 预加载、触发事件、计数复位、周期和占空比计算，最后在硬件上读取约 0.999 ms 和 19.2% 的结果并讨论误差。这一抽样直接支持其“原理细、逐行代码、项目化验证”的课程定位。

因此，该课程从“根据评论值得继续验证”升级为“技术章节已经验证，优先推荐”。它的高分来自教学和工程价值，不来自隐藏性。

## 方法结论

1. 多 P 课程必须同时保存 `episode_score` 与 `course_sample_score`；两者不能共用一个推荐分。
2. 语义抽样比简单取首、中、尾更有效：目录标题可以主动覆盖基础原理、外设和实验。
3. 课程级评价仍需报告覆盖率。本轮仅覆盖 4/59 和 4/54，不能声称审阅了整套课程。
4. 下一轮应把“证据引用”加入正式 Schema，并让评分明确回指某个 P 和字幕证据类型。
