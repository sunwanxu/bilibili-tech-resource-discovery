## 关键判断

`BV1Cu4y1e732` 是当前最值得继续验证的隐藏资源候选：只有 367 播放，但证据具体到 PID 三闭环、编码器接口、测速/位置反馈和源码文件，评论还提供了源码文章。它的“可能隐藏价值”高于 DeepSeek 给出的 4 分，差异主要来自 Codex 把低热度与技术具体性作为该独立维度的直接证据。

`BV1C4421Z7t8` 的工程与资源价值较高，但播放量超过 57 万，不应因为内容好就同时获得高“隐藏价值”。

三个多 P/系列条目的当前结果只代表第一 P。尤其课程介绍不能代表整套课程质量；在解决多 P 和字幕之前，不应将低分用于课程推荐。

## 发现的模型问题

DeepSeek 对没有评论正文的 `BV11X4y1j7si` 给出了 `comment_value=4`，而 Codex 依据缺失证据给 0。后续 Schema 应为每个分数增加 `evidence_refs`，并在相应证据为空时由程序强制将评论价值设为 0，而不是依赖模型自律。
