# Phase 1 实验结果（2026-08-10，2026-08-11 登录态复测）

## 本轮是否证明链路成立

成立：`BVID → 元数据/字幕/有界评论 → 原始 JSON → 分析器 → JSON + Markdown` 已对 5/5 个 STM32 样本跑通。首次无 Cookie 测试的字幕覆盖率为 0/5；使用用户合法导出的登录态 Cookie 后，字幕文本覆盖率提升到 4/5，评论首屏读取成功率为 5/5。

## 登录态字幕与评论复测（2026-08-11）

导出文件先被机械筛选为仅含 `*.bilibili.com` 的 Netscape Cookie 文件，项目没有使用其中其他站点的 Cookie。复测读取并保存了字幕文本与最多 20 条评论；不下载视频或音频。

| BVID | 字幕语言 | 字幕字符数 | 评论样本数 | 警告 |
|---|---|---:|---:|---:|
| BV1Cu4y1e732 | `ai-zh` | 2,861 | 5 | 0 |
| BV1Dh411x7sK | 无 | 0 | 1 | 0 |
| BV1r1moYxEo8 | `ai-zh` | 4,633 | 20 | 0 |
| BV1C4421Z7t8 | `ai-zh` | 6,010 | 20 | 0 |
| BV11X4y1j7si | `zh-CN` | 9,787 | 20 | 0 |

结论：字幕覆盖率 **4/5（80%）**；评论接口覆盖率 **5/5（100%）**。有界评论适配器每个视频只请求一个首屏、最多保留 20 条，5 个样本完整复测约 69 秒。`data/raw/*.json` 经敏感 Cookie 名称扫描未发现 `SESSDATA`、`bili_jct`、`DedeUserID` 或 `buvid3`。

## Codex 字幕增强复评

字幕与评论加入后，Codex 已完成第二轮独立评价，详见 `docs/codex-evaluation-v2.md` 和 `data/evaluations/codex-2026-08-11-subtitles.json`。主要变化如下：

- `BV1Cu4y1e732` 的推荐分从 8.0 降至 5.5：主题具体且播放低，但字幕显示讲解主要是模块概述，没有兑现标题暗示的代码深度。
- `BV11X4y1j7si` 从 2.0 升至 8.0：当前第一 P 仍只是介绍，但课程设计清晰，且多条具体、高互动评论对整套课程形成了较强交叉验证。
- `BV1C4421Z7t8` 从 8.0 降至 6.5：项目和资料价值高，但具体评论对教学顺序、原理铺垫和 HAL 内容提出了重复且可核验的质疑。

这进一步证明“内容价值”“课程推荐”和“隐藏价值”必须是独立维度；高推荐课程不一定是隐藏资源，低播放和技术化标题也不保证高知识密度。

## 多 P 语义抽样复评

新增 `bhka sample <BVID> --parts 4` 后，对两套课程完成真实验证：分别枚举 59 和 54 个分 P，并各抽取介绍、基础、外设、实验四个角色。8 个分 P 中 7 个获得字幕，全部零告警，原始数据保存于 `data/raw_parts/`，抽样清单保存于 `data/samples/`。

课程级抽样结果推翻了“第一 P 分数可以近似整套课程”的假设：

- `BV1r1moYxEo8` 的课程推荐为 6.5。PWM 和 ADC 章节包含数据手册、参数计算、代码配置和硬件检查，明显高于 P1 介绍所反映的价值。
- `BV11X4y1j7si` 的课程推荐为 9.0。SPI 与 PWM 测量章节验证了手册驱动、原理解释、逐行代码和硬件实测的完整证据链。

完整判断见 `docs/codex-multipart-evaluation.md`；结构化结果见 `data/evaluations/codex-2026-08-11-multipart.json`。

## 成功项

- BVID 和完整 URL 解析。
- 标题、简介、作者、发布时间、播放、点赞、评论数、标签、时长获取。
- 原始数据与分析数据分离保存。
- 登录态字幕文本在 4/5 样本成功解析并保存。
- 有界评论提取在 5/5 样本成功，最多保留 20 条。
- Pydantic Schema、OpenAI Responses 适配器、Markdown 报告。
- DeepSeek V4 Pro OpenAI-compatible JSON Output 适配器和 5/5 在线调用。
- 5 个测试通过，Ruff 零告警。

## 失败与限制

- `bilisearch5:STM32` 返回 HTTP 412；搜索链路不可靠。
- 5 个样本均无匿名字幕；登录后 4 个可取得中文字幕，1 个仍无字幕。
- 收藏与投币未由选定适配器暴露，保持 `null`。
- 多 P 视频当前按 `noplaylist` 只分析首 P；标题会带 `p01`。
- 评论仅取按热度排序的首屏样本，不代表完整评论区，也不适合推断总体观点分布。
- DeepSeek V4 Pro 已在线验证；OpenAI 分析器尚未在线验证。
- Schema 合法不代表判断可靠：`BV11X4y1j7si` 没有评论正文，但模型仍给出 `comment_value=4`，说明需要增加字段级证据约束或后处理规则。

## AI 判断是否有意义

链路层面有意义，评分有效性尚不能下结论。DeepSeek 能区分“课程介绍首 P”和“明确描述源码、PID、编码器或工程实践”的样本，并主动陈述证据缺失；但也出现了无评论却给评论价值 4 分的未落地判断。无字幕时，它仍主要在评价标题和简介，而不是视频本身。下一轮首先需要人工标注和字段级 grounding 检查，而不是增加架构复杂度。
